# runes.co.kr 비주얼 디자인 브리프

작성일: 2026-06-04

## 디자인 키워드

`Quiet Rune Archive`

한국어명 후보:

- 조용한 룬 기록소
- 룬 아카이브
- 룬스톤 입문서
- 오늘의 룬 기록장

## 피해야 할 무드

- 검정+빨강 악마 오컬트
- 보라색 우주/별자리 과다
- 바이킹 전사/피/불꽃/해골
- 게임 판타지 UI
- 크리스털샵 쇼핑몰
- AI 이미지가 과한 마법학교풍

## 가져갈 무드

- 조용한 자료실
- 따뜻한 종이
- 룬스톤과 린넨
- 손으로 기록하는 노트
- 북유럽 감성은 아주 약하게
- 모바일에서 읽기 쉬운 학습 앱
- 커뮤니티지만 지저분하지 않은 게시판

## 타이포그래피

- 본문: Pretendard 또는 Noto Sans KR
- 제목 보조: Noto Serif KR 또는 Gowun Batang
- 룬 문자: 시스템 Unicode + 별도 SVG 보정

원칙:

- 본문 가독성이 최우선이다.
- 제목은 과하게 장식하지 않는다.
- 룬 문자는 크게 보여주되, 설명은 차분하게 읽히게 한다.

## 첫 화면 구성

첫 화면은 랜딩페이지보다 학습 포털이어야 한다.

```txt
상단 내비게이션
  로고
  룬 해석
  무료 리딩
  스프레드
  임상/사례
  자료실

히어로
  제목: 룬스톤 처음이에요?
  설명: 24개의 룬 문자부터 오늘의 리딩까지, 한국어로 천천히 배우는 룬 입문서.
  버튼: 왕초보 가이드 / 오늘의 룬 / 24룬 보기

바로가기 카드 4개
  이 짝대기는 무슨 뜻인가요?
  룬스톤은 어떻게 뽑나요?
  스프레드는 어떻게 하나요?
  다른 사람들은 어떻게 해석했나요?
```

## 핵심 컴포넌트

- 룬 알파벳 보드
- 오늘의 룬 카드
- 왕초보 체크리스트
- 단계별 리딩 위저드
- 스프레드 캔버스
- 룬별 해석 페이지
- 영상 강의 블록
- 임상/사례 피드
- AI 사진 분석 업로드 카드
- 유료 플랜 비교표

## 모바일 UX

모바일 첫 화면 하단 고정 액션:

- 오늘의 룬
- 24룬
- 스프레드
- 사례

사진 분석은 모바일 중심으로 만든다.

- 카메라 열기
- 촬영 가이드 오버레이
- 인식 결과 수정
- 해석 보기
- 저장/PDF

## UI 라이브러리 방향

기본:

- shadcn/ui
- Tailwind CSS
- lucide-react

선택적 효과:

- Magic UI
- Aceternity UI
- Cult UI

주의:

- 애니메이션은 적게 쓴다.
- 배경 효과는 거의 쓰지 않는다.
- 모바일 성능과 가독성이 먼저다.

## 레이아웃 톤

- 큰 랜딩 카드보다 정보가 바로 보이는 포털형.
- 카드 반경은 작게, 8px 이하.
- 게시판은 조용하고 읽기 쉬운 리스트형.
- 룬 상세 페이지는 백과사전 + 노트 + 사례 댓글 구조.
- 히어로는 실물 룬스톤 사진을 쓰되, 텍스트는 카드에 가두지 않는다.

## 디자인 레퍼런스 활용

- shadcn/ui: 기본 컴포넌트와 접근성 있는 폼/탭/다이얼로그.
- shadcn blocks: 헤더, 히어로, 가격표, 대시보드, 사이드바 참고.
- Aceternity UI: 필요한 경우 미세한 인터랙션만 참고.
- Magic UI/Cult UI: AI 분석 화면과 업로드 카드에 제한적으로 참고.

## 페이지별 무드

### `/beginner`

가이드북, 친절함, 체크리스트.  
문장이 짧고 단계가 선명해야 한다.

### `/runes/[id]`

백과사전 + 오라클 해석.  
상단에는 큰 룬 문자, 아래에는 기초/역사/현대 해석/사례 탭.

### `/reading/*`

의식적인 분위기보다 사용 순서가 중요하다.  
질문 입력, 스프레드 선택, 룬 뽑기, 기록 저장 순서.

### `/cases`

커뮤니티지만 과하게 SNS처럼 만들지 않는다.  
검색, 필터, 룬별 태그, 질문 주제가 중요하다.

### `/ai-photo`

도구 화면.  
사진 업로드, 인식 확인, 해석 생성, 저장/PDF가 명확해야 한다.
