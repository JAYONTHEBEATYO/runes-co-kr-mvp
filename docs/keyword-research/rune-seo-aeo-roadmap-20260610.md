# 룬스 검색 키워드 발행 로드맵

작성일: 2026-06-10

이 문서는 runes.co.kr의 검색 유입을 만들기 위한 키워드 수집, 콘텐츠 클러스터, 발행 순서, SEO/AEO 적용 기준을 정리한 내부 기획서다. 목적은 단순히 "룬"이라는 단어를 반복하는 것이 아니라, 실제 초보 사용자가 검색창에 입력할 법한 질문을 사이트 구조와 글 주제로 연결하는 것이다.

## 이번에 만든 수집 도구

### 1. 자동완성 기반 키워드 수집

파일:

- `tools/keyword-research.mjs`
- `docs/keyword-research/rune-keyword-research.json`
- `docs/keyword-research/rune-keyword-research.csv`
- `docs/keyword-research/rune-keyword-research.md`

수집 범위:

- Google Suggest 한국어/한국 지역
- Google Suggest 영어/미국 지역
- Naver 자동완성
- 수동 시드 키워드

현재 결과:

- 전체 후보: 189개
- 클러스터: 9개
- 주요 클러스터: 룬스톤, 엘더 푸사르크, 룬 뜻/해석, 룬 리딩, 룬 캐스팅, 바인드 룬, 역사/팩트체크, 도구/타투

주의:

- 자동완성은 검색량이 아니라 사용자가 실제로 입력하는 검색 의도의 신호다.
- 한국어 룬 시장은 검색량이 작을 가능성이 높으므로, 자동완성에 잡힌 키워드는 작은 시장에서 특히 중요하다.
- 게임/판타지 노이즈가 섞일 수 있어 `점술가 길드`, `비전 룬`, `runescape`, `rune factory`, `runelite` 같은 키워드는 필터링했다.

### 2. Google Trends 자동화

파일:

- `tools/google-trends-runes.py`
- `docs/keyword-research/google-trends-runes.json`

사용 도구:

- `pytrends`
- `pandas`
- `urllib3<2`

현재 상태:

- `pytrends`와 의존성은 설치 완료.
- Google Trends 비공식 API 호출은 가능하도록 구성했다.
- 현재 실행에서는 한국어 핵심 묶음과 영어 핵심 묶음은 Google 측 429 제한으로 실패했고, 영어 상업 키워드 묶음은 일부 성공했다.
- 한국 기준 영어 상업 키워드 묶음에서는 `rune stones set`과 `rune tattoo`가 간헐적 상대 관심도를 보였고, `rune casting cloth`, `bind runes`, `rune translator`는 거의 0에 가까운 신호로 기록됐다.
- 이 실패는 코드 오류라기보다 Google Trends 비공식 호출의 구조적 한계다. 스크립트는 실패해도 전체 자동화가 멈추지 않고 `status: error`와 원인 메시지를 남기게 했다.

판단:

- Google Trends는 정확한 월 검색량을 주는 도구가 아니라 0-100 상대 관심도 지표다.
- 실무에서는 Google Search Console, Google Ads Keyword Planner, Naver Search Advisor, 네이버 검색광고 키워드 도구, Ahrefs/Semrush/Glimpse/SerpApi류 유료 데이터로 보강해야 한다.
- 현재 단계에서는 자동완성 + 사이트 내부 콘텐츠 설계가 더 실용적이다.

## 콘텐츠 클러스터

### A. 왕초보 입문 클러스터

목표:

룬스톤을 처음 산 사람이 "이걸 대체 어떻게 쓰는 건지" 이해하게 만드는 영역이다. 타로 입문자가 카드 이름, 셔플, 스프레드, 질문법을 먼저 배우는 것처럼 룬스톤도 사용 순서부터 설명해야 한다.

발행 후보:

1. 룬스톤 사용법: 처음 산 사람이 바로 따라 하는 7단계
2. 룬스톤 뜻: 돌에 새긴 기호가 왜 리딩 도구가 되었을까
3. 룬스톤 뽑는 법: 질문을 정하고, 섞고, 고르고, 기록하는 순서
4. 룬스톤 보는 법: 초보자가 해석할 때 가장 많이 실수하는 지점
5. 룬스톤 세트 고르는 법: 원석, 나무, 카드형 룬의 차이

전환:

- 무료 리딩
- 룬스톤 키트
- 입문 PDF
- 유튜브 왕초보 영상

### B. 룬 문자/엘더 푸사르크 클러스터

목표:

검색자가 "룬 문자 뜻", "엘더 푸사르크", "바이킹 룬 문자"를 찾을 때 정확한 개념을 제공한다. 이 영역은 점술보다 역사와 문자 체계 설명의 비중이 높아야 한다.

발행 후보:

1. 룬 문자는 무엇인가요? 고대 게르만 문자에서 현대 룬스톤까지
2. 엘더 푸사르크란? 24룬을 이해하기 위한 가장 쉬운 설명
3. 엘더 푸사르크 24룬 뜻 표
4. 엘더 푸사르크와 영거 푸사르크 차이
5. 바이킹 룬 문자라고 부를 때 조심해야 할 점

전환:

- 24룬 상세 페이지
- 24룬 표 다운로드
- 룬 문자 입문 전자책

### C. 룬 리딩/점술 방법 클러스터

목표:

룬을 실제로 점술에 쓰려는 사람에게 "질문을 어떻게 만들고, 어떤 방식으로 뽑고, 어떤 순서로 해석하는지"를 안내한다. 이 영역은 사이트의 핵심 서비스인 무료 리딩과 바로 연결된다.

발행 후보:

1. 룬 점술은 어떻게 보나요? 초보자를 위한 룬 리딩 순서
2. 룬 리딩 질문법: 좋은 질문과 애매한 질문의 차이
3. 1룬, 3룬, 5룬 리딩은 언제 쓰면 좋을까
4. 룬 리딩 스프레드: 타로 스프레드와 비슷하지만 다른 점
5. 룬스톤 해석 기록법: 같은 룬을 반복해서 뽑았을 때 보는 법

전환:

- 무료 리딩
- 유료 심화 리딩
- 리딩 결과 PDF
- 프리미엄 해설서

### D. 캐스팅 클러스터

목표:

룬스톤을 단순히 뽑는 방식이 아니라 던져서 위치, 거리, 방향, 중심과의 관계를 읽는 방식까지 소개한다. 단, 역사적 사실과 현대 오라클 관습을 섞어 말하지 않도록 주의한다.

발행 후보:

1. 룬 캐스팅이란? 룬스톤을 던져 읽는 현대적 방법
2. 룬스톤 던지는 법: 천, 중심점, 질문, 기록의 순서
3. 룬 캐스팅 천은 꼭 필요할까?
4. 룬스톤을 던질 때 떨어진 위치는 어떻게 읽을까
5. 룬 캐스팅과 룬 뽑기, 초보자에게 더 쉬운 방식은?

전환:

- 캐스팅 천
- 룬스톤 키트
- 캐스팅 PDF 양식

### E. 팩트체크/칼럼 클러스터

목표:

룬 시장은 현대 오라클 문화, 뉴에이지 해석, 역사 자료가 뒤섞여 있다. 그래서 runes.co.kr은 "믿을 수 있는 입문 사이트"가 되려면 팩트체크 글이 필요하다.

발행 후보:

1. 빈 룬은 진짜 25번째 룬일까?
2. 룬스톤에서 역방향을 꼭 봐야 할까?
3. 그림자 해석은 공식 룬 용어일까?
4. 바인드 룬은 마음대로 만들어도 될까?
5. 룬 문자 타투를 하기 전에 알아야 할 것

전환:

- 브랜드 신뢰
- 유튜브 해설 콘텐츠
- 심화 전자책

### F. 상품 전환 클러스터

목표:

정보성 글만으로 끝내지 않고 실물 룬스톤, 해설서, PDF, 강의, 오라클 카드형 상품으로 연결한다. 단, 초반에는 과한 판매 문구보다 "처음 쓰는 사람이 덜 헤매게 하는 구성"을 강조하는 편이 좋다.

발행 후보:

1. 룬스톤 세트 구성품은 무엇이 좋을까?
2. 룬스톤 구매 전 확인할 것: 재질, 각인, 보관, 설명서
3. 룬스톤 해설서가 필요한 이유
4. 룬 오라클 카드와 룬스톤의 차이
5. 입문자가 쓰기 좋은 룬스톤 키트 구성

전환:

- 룬스톤 세트
- 프리미엄 설명서
- PDF 결과지
- 영상 강의

## SEO/AEO 작성 규칙

### 제목

- 검색어를 그대로 넣되, 사람이 읽기 자연스러운 문장으로 쓴다.
- 예: `룬스톤 사용법: 처음 산 사람이 바로 따라 하는 7단계`
- 피해야 할 제목: `룬 룬스톤 룬문자 룬 점술 완벽정리`

### 도입부

- 첫 300자 안에 검색자의 문제를 직접 받아준다.
- 예: "룬스톤을 샀는데 막상 손에 쥐고 나면 가장 먼저 드는 생각은 대개 비슷합니다. 이걸 어떻게 뽑아야 하지? 질문을 먼저 해야 하나? 섞는 순서가 따로 있나?"

### 본문 구조

- H2는 검색자가 물어볼 법한 질문형으로 만든다.
- H3는 절차, 기준, 예시를 나눈다.
- FAQ는 4-6개를 둔다.
- 각 글마다 관련 페이지 3개 이상을 내부 링크로 연결한다.

### AEO 기준

AI 검색과 답변형 검색에 잡히려면 문단마다 답이 선명해야 한다.

- "룬스톤 사용법은 질문 정하기, 룬 섞기, 룬 뽑기, 위치 확인, 해석, 기록, 재질문의 순서로 진행할 수 있다."
- "엘더 푸사르크는 보통 24개의 룬으로 구성된 초기 게르만 룬 문자 체계를 가리킨다."
- "룬 점술에서 역방향은 현대 리더에 따라 쓰이지만, 입문자용 기본 리딩에서는 쓰지 않아도 된다."

### 구조화 데이터

글마다 다음 JSON-LD를 우선 적용한다.

- Article
- FAQPage
- BreadcrumbList

24룬 개별 페이지는 다음 구조도 고려한다.

- DefinedTerm
- Thing
- Article
