# runes.co.kr 미션과 커뮤니티 방향

작성일: 2026-06-04

## 한 줄 미션

`runes.co.kr`은 한국어로 룬을 공부하고, 직접 리딩하고, 실제 사례를 함께 쌓는 국내 룬 지식 커뮤니티다.

## 브랜드 선언문

룬은 정답을 말해주는 도구가 아니라, 질문을 더 선명하게 만들고 선택을 돌아보게 하는 상징 언어다.  
`runes.co.kr`은 역사적 룬 문자와 현대 오라클 리딩을 구분해 설명하고, 초보자도 실제 상황에 적용할 수 있는 한국어 해석과 사례를 축적한다.  
우리는 과장된 예언보다 구체적인 질문, 맹신보다 기록, 복붙 해석보다 실제 경험을 중요하게 다룬다.

## 사이트 포지션

- 국내 첫 룬 전문 정보/커뮤니티 사이트
- Elder Futhark 24룬 한국어 해석 DB
- 룬 리딩 스프레드와 질문 자료실
- 사용자 리딩 사례 공유
- 룬스톤/오라클 카드/실물 키트 정보 허브
- 역사 자료와 현대 점술 자료를 구분하는 안전한 아카이브

## 더메인타로에서 가져올 구조

- 무료 테스트/오늘의 룬
- 스프레드 모음
- 공부 자료
- 임상/사례 공유
- 자료 모음
- 블로그/업데이트

- 후원/복채

## runes.co.kr 메뉴 초안

1. 룬 문자 해석
   - Elder Futhark 24룬
   - 룬별 정방향/역방향
   - 질문별 해석: 연애, 일, 돈, 관계, 선택, 자기이해
   - 룬 조합 해석

2. 무료 룬 리딩
   - 오늘의 룬
   - 1룬 리딩
   - 3룬 리딩
   - 5룬 리딩
   - Yes/No 룬

3. 룬 스프레드
   - 초보자용
   - 연애/재회
   - 진로/사업
   - 금전
   - 자기이해
   - 실물 룬스톤 배열법

4. 룬 임상/사례
   - 룬별 사례 공유
   - 질문별 사례
   - 데일리 룬 기록
   - 리딩 후기

5. 룬 공부 자료
   - Elder Futhark란?
   - 바이킹 룬과 Elder Futhark 차이
   - 룬 이름 한국식 발음
   - 룬 시와 역사 자료
   - 룬 오용/주의 상징

6. 자료실
   - 공개 도메인 자료
   - 추천 도서
   - PDF 색인
   - 이미지/폰트/Unicode 자료

7. 룬스톤/오라클 키트
   - 실물 룬스톤 소개
   - 오라클 카드
   - QR 리딩 키트
   - 제작/사입/수입 기록

8. 커뮤니티
   - 자유게시판
   - 질문 게시판
   - 리딩 교환
   - 자료 제보

## 핵심 콘텐츠 원칙

- 룬 해석은 정답이 아니라 해석 가능성으로 제시한다.
- 역사적 사실과 현대 오라클 해석을 섞어 단정하지 않는다.
- 사용자가 올린 사례는 맥락, 질문, 뽑힌 룬, 실제 결과를 중심으로 축적한다.
- 무속/오컬트 분위기보다 공부 가능한 자료실, 기록장, 커뮤니티 톤을 우선한다.
- 실물 키트는 커뮤니티 신뢰가 생긴 뒤 확장한다.

## MVP 우선순위

1. 24룬 해석 사전
2. 오늘의 룬/1룬/3룬 무료 리딩
3. 룬별 임상/사례 작성 기능
4. 스프레드 자료실
5. 룬 공부 자료 10개
6. 자료실과 PDF 색인
7. 회원가입/닉네임/내 기록
8. QR 실물 키트 연동

- “미래를 정확히 맞힌다”는 식의 과장

- 역사적 Elder Futhark와 현대 Wyrd 룬을 같은 체계처럼 설명
- 극단주의 오용 가능 상징을 멋으로 소비
- 룬스톤 쇼핑몰만 먼저 만드는 방향
