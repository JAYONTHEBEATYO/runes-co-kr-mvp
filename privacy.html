개인정보 처리방침

룬스는 무료 리딩에 필요한 정보만 받고, 목적이 끝난 기록은 오래 보관하지 않습니다. 아래 내용은 2026년 7월 20일부터 적용됩니다.

어떤 정보를 처리하나요?

무료 리딩을 만들 때 질문, 선택한 주제와 스프레드, 뽑힌 룬, 생성된 해석을 처리합니다. 사용자가 별자리 개인화를 펼쳐 직접 입력한 경우에만 양력 생일, 태어난 시간, 성별, 출생 지역, 현재 지역과 주소 검색 결과를 함께 처리합니다.

반복적인 자동 호출을 제한하기 위해 접속 IP를 서버 안에서 즉시 익명 해시로 바꿉니다. 원래 IP 주소, 브라우저 종류와 이전 방문 주소는 리딩 기록에 저장하지 않습니다.

어디에 사용하나요?

입력 정보는 룬 리딩 생성, 선택한 경우의 별자리·통합 운세 보조 계산, 서비스 오남용 방지, 관리자 품질 점검에 사용합니다. 광고 프로필을 만들거나 제삼자에게 판매하지 않습니다.

외부 서비스는 무엇을 사용하나요?

웹사이트와 비공개 기록 저장에는 Vercel을 사용합니다. 리딩 문장 생성에는 Google Gemini API를 사용하며, 출생 시간·성별·출생 지역이 충분히 입력된 경우에는 타저씨 통합엔진 API가 보조 계산에 사용될 수 있습니다. 각 서비스에는 해당 기능에 필요한 입력만 서버에서 전달하며 API 키는 브라우저에 공개하지 않습니다.

얼마나 보관하나요?

무료 리딩 기록은 생성일부터 최대 90일 동안 비공개로 보관한 뒤 자동 삭제합니다. 오남용 방지를 위한 익명 호출 기록은 최대 3일 동안 보관합니다. 사용자가 결과 화면의 ‘내 리딩 기록 삭제’ 버튼을 누르거나 관리자가 삭제하면 보관기간 전에도 즉시 삭제합니다.

사용자가 선택할 수 있는 것

별자리 개인화 정보는 모두 선택 입력입니다. 생년월일, 시간, 성별, 지역을 입력하지 않아도 룬 리딩을 이용할 수 있습니다. 리딩 결과에 표시되는 삭제 버튼은 해당 결과를 만든 브라우저에만 제공되는 일회성 삭제 정보로 작동하며, 룬스는 그 삭제 정보를 원문으로 저장하지 않습니다.

주의할 점

질문란에는 주민등록번호, 전화번호, 계좌번호, 정확한 집 주소, 다른 사람의 민감한 개인정보를 적지 마세요. 룬 리딩은 자기 성찰을 돕는 콘텐츠이며 의료·법률·투자·안전 판단을 대신하지 않습니다.

방침 변경

처리 항목이나 보관기간이 달라지면 이 페이지의 적용일과 내용을 먼저 갱신합니다. 동의 범위를 크게 바꾸는 기능은 기존 동의와 분리해 안내합니다.
